# Hand Cursor

Управление курсором мыши через веб-камеру — наклоном кисти.

## Как работает

1. **Python** — захват камеры, MediaPipe HandLandmarker, вычисление наклона кисти
2. **Rust** — evdev uinput, создание виртуальной мыши

Наклоняешь руку → курсор едет в ту же сторону. Сильнее наклон → быстрее.

## Требования

- Linux с `/dev/uinput` (доступ на запись)
- веб-камера
- Python 3 + зависимости
- Rust

## Установка

```bash
# Python зависимости
.venv/bin/pip install -r requirements.txt

# Rust бинарник
cargo build --release
```

## Запуск

```bash
.venv/bin/python -m vision.main | ./target/release/open-tracker
```

## Управление

| Жест | Действие |
|------|----------|
| Рука вертикально | Нейтраль |
| Наклон кисти | Курсор движется в сторону наклона |
| Пинч (свести большой + указательный) | Клик |
